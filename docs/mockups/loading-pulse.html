HoopRadar loading pulse

The status text fades between 35% and 100% opacity on a 1s loop while work is in progress. A status is treated as "busy" (and pulses) when its text ends with an ellipsis, so "Loading..." and "Refreshing..." animate, while a finished "Updated ..." or an error does not.

How it is implemented

/* src/ui/filter-bar.ts  (status pill) */
.status[data-state="busy"] {
  opacity: 1;
  animation: hoopradar-pulse 1s ease-in-out infinite;
}
@keyframes hoopradar-pulse {
  0%, 100% { opacity: 0.35; }
  50%      { opacity: 1; }
}

// setStatus marks any trailing-ellipsis message as "busy":
const busy = state === "ok" && /\.\.\.$/.test(text);
statusEl.dataset["state"] = busy ? "busy" : state;

/* src/ui/spider-tooltip.ts  (card loading text) */
[data-role="loading"] { animation: hoopradar-pulse 1.1s ease-in-out infinite; }
